# Data Processing Engine using Flask, Pandas, and NumPy

A simple web-based data analysis application built using Flask, Pandas, and NumPy.

Users can:
- Upload CSV files
- View dataset summary
- Preview table data
- Check missing values
- Filter data
- Sort data
- Limit number of rows displayed

---

# Features

## Upload CSV File
Upload any CSV dataset through the browser.

## Dataset Summary
Displays:
- Total rows
- Total columns
- Column names

## Missing Values Detection
Shows missing/null values for each column.

## Data Preview
Displays the first few rows of the dataset in table format.

## Filter Data
Users can:
- Select a column
- Select a value
- Choose number of rows to display
